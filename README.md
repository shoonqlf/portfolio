# Samy Saïdj — Portfolio v2 🚀

## Lancer en local
1. Installer Node.js LTS : https://nodejs.org
2. Dans ce dossier :
```
npm install
npm run dev
```
3. Ouvrir http://localhost:3000

## C'est quoi
Un voyage en fusée dans un système solaire stylisé : décollage, atterrissage sur chaque planète-projet, journal de bord, redécollage. FR/EN · Mode recruteur · Chatbot · Easter egg CTF (ouvre la console 👀).
